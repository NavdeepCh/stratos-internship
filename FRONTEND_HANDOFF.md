# V5 backend handoff
Phone-only lookup: POST /my-internships-lookup {phone} returns {enrollments:[{categoryName,domainName,planName}]}. Return only minimal non-sensitive summaries; rate-limit and prevent enumeration; never return private records, IDs or documents. Empty array only after successful lookup.
Category registration POST /register-category no longer requires phone OTP. Validate input, rate-limit, deduplicate requestId, derive trusted amount and return registrationId, expectedAmountPaise and a short-lived unguessable checkoutToken scoped to that registration. Free enrollment also returns Confirmed and Not Required. Paid order and verification endpoints require this scoped bearer token; verify captured amount, signature and ownership. No live backend changes. Existing Instant flow unchanged.
