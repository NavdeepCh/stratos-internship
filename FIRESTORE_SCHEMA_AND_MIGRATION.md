# Proposed registration schema
Existing orders path: artifacts/stratos-global-edu/public/data/orders/{registrationId}. Keep userId as verified Firebase UID for new enrollments. Add categoryId (instant, short-term, long-term, summer), categoryName, domainId, domainName, planId, planName, durationDays, expectedAmountPaise, amountPaidPaise, paymentRequired, paymentStatus, paymentVerified, enrollmentStatus, projectStatus, certificateIncluded, instantPdfIncluded, enrollmentDocumentStatus, enrollmentDocumentId, enrollmentDocumentEmailStatus, completionCertificateStatus, completionCertificateId, createdAt and updatedAt. One registration per category enrollment; derive multi-category combinations from owned records. Free plans: Not Required, zero amount, no payment ID. Never infer payment from a browser callback. Legacy records must be reconciled with Razorpay and linked only after verified ownership. No migration executed. Review rules against live configuration before deployment.
